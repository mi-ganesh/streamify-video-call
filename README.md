# 💬 Real-Time Chat Application (MERN Stack)

A full-stack real-time chat application built using the **MERN stack** with secure authentication, user management, and real-time messaging. The application supports protected routes, cookies-based authentication, and production-ready frontend deployment.

---

## 🚀 Features

- 🔐 User Authentication (Register / Login / Logout)
- 🍪 Cookie-based authentication
- 👥 User management & friend system
- 💬 Real-time chat functionality
- 🛡️ Protected API routes
- 🌐 CORS-enabled frontend-backend communication
- 📦 Production-ready frontend build serving
- 🗄️ MongoDB database integration

---

## 🛠️ Tech Stack

### Backend
- **Node.js**
- **Express.js**
- **MongoDB**
- **Mongoose**
- **JWT Authentication**
- **Cookie Parser**
- **CORS**
- **dotenv**

### Frontend
- **React**
- **Vite**
- **JavaScript**
- **CSS**
